Gene Expression Viewer

Example: TraesCSU03G0001100, TraesCSU03G0002800, TraesCSU03G0002900LC
The uploaded file should contain one gene ID per line, or gene IDs in the first column of a TXT/CSV/TSV file.
The current website supports single-cell search for two genomes, including Chinese Spring and Kronos. The Chinese Spring dataset is based on root single-cell data, while the Kronos dataset is based on spike single-cell data. The DotPlot is generated dynamically from dotplot_data.tsv instead of pre-generated PNG images.
