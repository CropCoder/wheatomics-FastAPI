About this dataset & data sources
  • Coverage: 9 PTM types — phosphorylation, N-glycosylation, S-acylation, 2-hydroxyisobutyrylation, crotonylation, succinylation, malonylation, acetylation and ubiquitination.
  • Predictions & confidence: rows are model predictions; Confidence is the source tool's confidence class. Non-PTM rows are the negative class and are hidden by default — use the Show selector to include them.
  • Scores: tool-specific. N-glycosylation scores are e-values (smaller = stronger); other types report 0–1 scores (larger = stronger). Do not compare scores across PTM types.
  • Protein IDs: exact match only. Standard gene-model proteins (e.g. TraesCS1A02G000100.1) and LC protein models (e.g. TraesCS1A02G000100LC.1) are indexed separately.
  • Data source: predictions generated with PlantPTM (Dou et al., Molecular Plant 2026), a protein-language-model framework covering 9 PTM types across six plant species; wheat predictions were imported from the PlantPTM output CSV files (all_pho.csv, all_NGly.csv, …). See References & data sources below. The CSV download follows the current Show selection.
  • Interpretation: every row is a computational prediction, not an experimental observation — use the confidence classes when prioritising sites.
