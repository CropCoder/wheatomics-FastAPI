WheatOmics integrates wheat multi-omics data on top of JBrowse, a fast and full-featured genome browser built with JavaScript and HTML5. It lets you obtain multiple levels of information simultaneously by querying a gene ID or a genomic region. Besides JBrowse, a growing set of analysis tools is provided for downstream work on genomic data.

For any question or suggestion, please contact Shengwei Ma (shengweima@icloud.com).
